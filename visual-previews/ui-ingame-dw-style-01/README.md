# DozenWar — UI ingame DW-STYLE-01

Bốn bảng concept tiếp nối UI Chọn chế độ. Bản thử, chờ người dùng duyệt; chưa thay UI hoặc luật chơi trong game.

1. **01-desktop-hud.png** — thanh lượt, timer, Hero, kỹ năng, trang bị, nhật ký, nút và trạng thái.
2. **02-hero-skills-equipment.png** — khung đơn vị, kỹ năng, chọn trang bị và mục tiêu.
3. **03-defense-results-dialogs.png** — phòng thủ, xác nhận kết thúc lượt/chơi lại, thông báo và thắng–thua–hòa.
4. **04-mobile-ingame.png** — ba bố cục màn dọc và các điều khiển mobile.

Ảnh concept tổng hợp, chưa phải asset UI tách riêng. Kích thước trong manifest là kích thước ảnh, không phải số đo từng thành phần. Nội dung/chỉ số và hình bàn cờ trên concept chỉ minh họa bố cục; khi triển khai cần dùng luật, dữ liệu và asset Hero/lính đã được duyệt trong game. Chưa xác nhận các mẫu này làm chuẩn.

Mở index.html để xem ảnh, hoặc mở trực tiếp từng PNG. manifest.json ghi kích thước, byte và SHA-256 của từng ảnh gốc.
